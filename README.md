# homebrew-piperace

Homebrew tap for [Piperace](https://piperace.com) — expose local ports through a
secure tunnel. macOS and Linux, Apple Silicon/arm64 and Intel/amd64.

## Install

```
brew install piperace/piperace/piperace
```

Then run `piperace`.

Installing by the full `owner/tap/formula` name trusts just this formula
automatically ([tap trust](https://docs.brew.sh/Tap-Trust), Homebrew 6.0+).
To use the short name instead:

```
brew tap piperace/piperace
brew trust --formula piperace/piperace/piperace
brew install piperace
```

## Upgrade

```
brew upgrade piperace
```

## Uninstall

```
brew uninstall piperace
brew untap piperace/piperace
```
